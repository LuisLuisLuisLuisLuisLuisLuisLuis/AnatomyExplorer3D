Working with the Tree

Selection

Select items via mouse click.
The selection of the two trees is always synchronized.
By the default, the selection of Tree and 3D view is not synchronized so that they don't override each other. Check Sync with 3D to synchronize Tree and 3D selection. Initially, this will adapt the tree selection to the selection of the 3D view.

Searching the tree

Type any text into the search field and hit Enter to highlight the first item containing it. Go to the next occurrence via Enter. Navigate the search via the buttons next to the search field or select all items that match the query via All. Check Regex to have your query be treated as RegEx.
AI Search
To be able to use AI search, you must provide an OpenAI API key. Do so by creating an environment variable on your computer called OPENAPI_API_KEY.
Check Show AI to show AI search.
Type your query into the newly appeared text area and hit Ask AI to send.
The AI will attempt to generate a RegEx to select all items corresponding to your request. To view your chat history with the AI, hit History. Ctrl+Click on any of the queries or answers to copy it to your clipboard.
Note: This feature still needs improving. The AI frequently makes mistakes, especially when there are many items to select.

Leaf Info

Click Leaf Info to show the distribution of direct parent nodes of all selected leaf nodes.

Working with the 3D view

The 3D view supports the following mouse interactions:
  • Click to select items
  • Drag to rotate
    • Ctrl+Shift+Drag to trigger continuous rotation
  • Scroll to zoom
    • Ctrl+Scroll to move vertically
    • Alt+Scroll to move horizontally
The 3D view supports the following keyboard interactions:
  • Ctrl+Arrow to move horizontally or vertically
  • Alt+Arrow to rotate

Drawing items

To be able to draw selected items from the tree view, you must first specify the location of the .obj files. Do so by File -> Find File Locations. Find the folder containing the Part-Of .obj files and click Select Folder. You will then be prompted to also find the folder containing the Is-A .obj files.

You may open any valid .obj file via File -> Open. However, they will not have a corresponding entry in the tree.

Miscellaneous

Undo-Redo

Undo-Redo is implemented for Expand, Collapse, Select All of, Select None, Draw in 3D, Remove (from 3D), Remove buttons and also color changes.
